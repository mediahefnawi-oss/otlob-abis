# نسخة الأندرويد (APK)

البناء بيتم على GitHub مجانًا (بدون حساب Expo أو جهاز كمبيوتر):
1. ضيف المتغير: GitHub ← المستودع ← Settings ← Secrets and variables ← Actions ← تبويب Variables ← New repository variable.
   الاسم `EXPO_PUBLIC_API_URL` والقيمة رابط الـ API (نفس القيمة المستخدمة في موقع Vercel). اختياري: `EXPO_PUBLIC_API_URL_BACKUP` برابط السيرفر الاحتياطي.
2. أنشئ ملف الـ workflow: Add file ← Create new file، الاسم `.github/workflows/build-apk.yml` والصق محتوى `build-apk.yml`.
3. Actions ← build-apk ← Run workflow. يستغرق حوالي 15–25 دقيقة.
4. بعد النجاح يتم نشر رابط تحميل ثابت: `https://github.com/اسمك/اسم-المستودع/releases/latest/download/otlob-abis.apk` (يعمل للجميع لو المستودع Public). ضعه من لوحة المالك ← «تطبيق الأندرويد» ← رابط تحميل التطبيق، فيظهر زر «حمّل تطبيق الأندرويد» في شاشة البداية بنسخة الويب.
5. أو افتح التشغيل الناجح وانزل لآخر الصفحة: Artifacts ← `otlob-abis-apk`، نزّله (ملف zip فيه الـ APK)، فكّه وثبّت الـ APK (يطلب السماح بالتثبيت من مصدر غير معروف).

## الفرق عن نسخة الويب
- رفع الصور (الروشتة، اللوجو، صور المنتجات) شغال من المعرض.
- التنبيهات: عند فتح التطبيق يهتز الموبايل عند وصول طلب جديد. لا يوجد صوت منبّه مستمر ولا إشعارات والتطبيق مغلق (تحتاج Firebase، مرحلة لاحقة).
- التوقيع بمفتاح تجريبي: يصلح للتثبيت المباشر، ولنشر جوجل بلاي نحتاج مفتاح توقيع رسمي.

## أيقونة التطبيق
من لوحة المالك ← «تطبيق الأندرويد» ارفع صورة مربعة (PNG/JPG). الأيقونة بتتثبت داخل ملف التطبيق وقت البناء، فبعد تغييرها شغّل `build-apk` من جديد وثبّت النسخة الجديدة. (تغيير أيقونة تطبيق مثبّت على الموبايل من السيرفر مباشرة غير ممكن في أندرويد.)

## الصلاحيات
التطبيق يطلب: الصور والكاميرا (للروشتة والمنتجات)، الاهتزاز، الإنترنت، الاتصال، والإشعارات. الإشعارات والتطبيق مغلق تحتاج ربط Firebase (مرحلة لاحقة).

## إشعارات الموبايل (Firebase) — مجاني
1. console.firebase.google.com ← Add project (أي اسم) ← داخل المشروع ← Add app ← Android ← اسم الحزمة بالظبط: `com.otlobabis.app` ← Register ← نزّل `google-services.json`.
2. ارفع `google-services.json` في مجلد المستودع الرئيسي على GitHub (جنب package.json).
3. Firebase ← Project settings ← Service accounts ← Generate new private key ← ينزل ملف JSON. افتحه وانسخ كل محتواه.
4. Vercel ← مشروع الـ API (otlob-abis) ← Settings ← Environment Variables ← الاسم `FIREBASE_SERVICE_ACCOUNT` والقيمة محتوى الملف كله. ثم أعد النشر. (ما تبعتوش في الشات.)
5. شغّل `build-apk` من جديد، ثبّت النسخة، افتح التطبيق، حسابي ← «تفعيل الإشعارات».
